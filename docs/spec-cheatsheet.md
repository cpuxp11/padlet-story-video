# spec2.js 비트 치트시트

챕터: `{ id:"ch1", nick:"이름칩", clips:["c1"], music:{...}, beats:[...] }`
- `nick` 상단 이름 칩. `clips` 이 챕터 **앞**에 끼울 촬영 클립. `music` 챕터 0초에 까는 음악(`"carry"` 면 앞 음악 이어감).
- 비트 길이: `g`(×0.43초) 또는 `d`(초). `build()` 를 쓰면 `s`(절대 초)로 쓰고 자동 변환.

| 타입 | 용도 | 예 |
|---|---|---|
| `title` | 오프닝 타이틀 | `{t:"title", g:6, l1:"소제목", l2:"소제목2", hero:"큰<br>제목", acc:["오렌지 단어"]}` |
| `stack` | 사진 스택 스크롤 | `{t:"stack", g:12, slow:true, items:[{img:"..."},{cap:"캡션"},...]}` |
| `card` | 라벨 + 큰 문장 | `{t:"card", g:7, label:"오늘의 질문", text:"왜<br><b>못 지켰을까?</b>", size:92}` |
| `chatpage` | 채팅 타이핑(아이 원문) | `{t:"chatpage", g:16, msgs:[{who:"me",text:"…",g:4},{who:"ai",text:"…",g:5}]}` |
| `order` | "아이가 다시 시켰다" 말풍선 + 이전 그림 흐리게 | `{t:"order", g:6, text:"…", bg:"이전그림.jpeg"}` |
| `still` | 폴라로이드 + 하단 자막(2줄 스택) | `{t:"still", g:8, src:"…", cant:-2, tag:"수정 전", flash:true, subs:[{at:0.5,text:"자막 <b>강조</b>"}]}` |
| `mv` | **뮤직비디오용** 폴라로이드/AI영상 카드 + 가사 한 줄씩 타이핑 | `{t:"mv", src:"…", cant:2, tag:"1절", lines:[{at:11.8,text:"…"},{at:18.3,text:"…",end:24.0}]}` / `{t:"mv", vid:"ai.mp4", tag:"…", tagc:"#E8590C", lines:[…]}` |
| `hero` | 펀치라인(스케일 펀치인 + 에코 행) | `{t:"hero", g:4, word:"돈 비", rows:4, dark:true, size:210}` |
| `panel` | 만화 컷 확대 순회 | `{t:"panel", g:12, src:"…", grid:"2x2", caps:[…], zoom:1.9}` |
| `answers` | 아이별 한 줄 답 표 | `{t:"answers", g:12, title:"세 개의 노래", rows:[["이름","한 줄"],…]}` |
| `endcard` | 엔드카드 | `{t:"endcard", g:11, src:"사진", l1:"…", l2:"…", s1:"…", s2:"…", credit:"Music: …"}` |

`mv` 의 `lines`
- `at` 표시 시작(비트 기준 초; `build()` 쓰면 절대 초). `end` 없으면 다음 줄 `at` 까지.
- 타이핑 속도는 줄 길이에 맞춰 자동(0.8~2.6초). 단어 단위 줄바꿈, 긴 줄은 2줄.
- 앞 비트에서 이미 뜬 줄을 다음 비트(그림 교체)에서도 이어가려면 같은 `at`(과거 시각)을 그대로 적는다 → 이미 다 쳐진 상태로 뜸.
- `<b>…</b>` 오렌지 강조.
- `<br>` 로 의미 단위 줄바꿈 지정(`"하늘에서 내려오는<br>초록빛 선물에"`). 안 주면 폭에 맞춰 아무 데서나 꺾인다 — 부모용 영상은 전 줄에 넣는 것을 권장.

`vid` 카드 좌표(assemble 이 합성): 흰 카드 left 22 / top 601 / 1036×598, 영상은 (40,619)에 1000×562. 16:9 소스 기준. 다른 비율이면 `scale=1000:562` 가 찌그러뜨리니 미리 16:9 로 패딩할 것.

## 과정 + 노래 합본 구조 (남해 2주차 최종본)
아이마다 챕터 한 쌍: **과정 챕터**(질문 카드 → 답 채팅 → 히어로 → 그림·수정 전후) → **노래 챕터**(후렴만).
- 과정 챕터는 `music` 없음 → `AUDIO.bridge` 가 채움. `bridge.jumps:[0,36.4,66.6,96.4]` 로 빈 구간마다 곡의 다른 프레이즈에서 시작.
- 노래 챕터는 `music:{file, ss:69.2, fadeOut:3}` — `ss` 는 첫 비트 `s` 와 같게. `build()` 로 노래 초 그대로 쓴다.
- 촬영 클립은 과정 챕터의 `clips:["c1","t1"]` (이름 컷 → 태블릿 타이핑 컷).
- 전체 예시: `examples/spec2.process-song.example.js`.

## 함정
- 이미지 로드 전 `offsetHeight` 측정 금지 — 카드 축소는 `naturalWidth` 기준(렌더러에 내장).
- `chatpage` 말풍선이 위로 넘치면 오래된 것부터 숨김(TOPLIM 270px).
- `still` 하단 자막은 폭이 980px 를 넘으면 폭에 비례해 자동 축소(화면 밖 잘림 방지).
- `stack` 동안 이름 칩은 숨겨짐.
- `hero` 는 `dark:true` 면 검정 배경+노랑, 아니면 크림+오렌지.
